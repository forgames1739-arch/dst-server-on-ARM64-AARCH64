# dst-server-on-ARM64-AARCH64 (in development)
DST ARM64 Docker Server is a ready-to-use solution for running a Don't Starve Together dedicated server on ARM (like Raspberry Pi or Oracle Cloud) via box64. It features effortless ARM64 execution, out-of-the-box Master and Caves Docker Compose sharding, optimized emulator settings, and automatic SteamCMD updates.
